Midnight Ocean

A collection of four dark Visual Studio Code themes with ocean-inspired accents.

Download latest VSIX Repository

Choose a style

All four themes customize the editor and workbench, including the sidebar, tabs, activity bar, status bar, panels, inputs, buttons, selections, and integrated terminal. They also provide syntax coloring tuned for low-glare dark backgrounds.

ThemeBackgroundPalette
Midnight Ocean#191923Ocean blue, sea-glass green, warm orange, and berry
Midnight Ocean Dusk#111827Sky blue, violet, mint, and golden yellow
Midnight Ocean Reef#081B1FReef teal, bright cyan, mint, and yellow
Midnight Ocean Ember#17171AIcy cyan, violet, mint, and warm orange

Types and numbers use warm accent colors; keywords, functions, and properties use each variant's brighter accents. Strings and comments use softer colors for contrast and visual hierarchy.

Install the theme

Install the latest release

Download the latest VSIX installer from the Releases page, or use the direct download:

Download the latest Midnight Ocean VSIX

In VS Code:

  1. Download midnight-ocean.vsix using the link above.
  2. Open the Extensions view (Ctrl+Shift+X).
  3. Open the More Actions menu (...) and choose Install from VSIX....
  4. Select the downloaded VSIX file.
  5. Open the Command Palette (Ctrl+Shift+P), run Preferences: Color Theme, and select one of the Midnight Ocean themes.

Alternatively, install from a terminal:

code --install-extension ./midnight-ocean.vsix

Build an installer from source

To package the current source instead of using the included VSIX, install Node.js and pnpm, then run:

pnpm install
pnpm run package

The package script runs vsce package --no-dependencies and creates a versioned .vsix file in the project directory (for example midnight-ocean-0.0.2.vsix).

Automated releases

Every push to main starts a GitHub Actions release workflow that increments the patch version, packages the extension, and creates a GitHub Release. The workflow publishes GitHub Releases only; publishing to the Visual Studio Marketplace is a separate, manual process.

Activate or switch themes

Open the Command Palette (Ctrl+Shift+P) and select Preferences: Color Theme. Choose Midnight Ocean, Midnight Ocean Dusk, Midnight Ocean Reef, or Midnight Ocean Ember.

Or set the theme directly in your VS Code settings.json:

{
  "workbench.colorTheme": "Midnight Ocean Dusk"
}

Publish to the Visual Studio Marketplace

To publish the extension on the Marketplace, create a publisher, update package.json with the publisher ID, and use vsce with a Marketplace personal access token. See the repository README for the full steps.
