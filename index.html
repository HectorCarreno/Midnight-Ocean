Install

Download the latest release

Get the VSIX from the Releases page and install it in VS Code.

Download midnight-ocean.vsix

Install in VS Code

  1. Open Extensions (Ctrl+Shift+X).
  2. Choose Install from VSIX... from the More Actions menu.
  3. Select the downloaded midnight-ocean.vsix.
  4. Open Command Palette (Ctrl+Shift+P) → Preferences: Color Theme and pick your theme.

Or install from terminal

code --install-extension ./midnight-ocean.vsix

Build from source

Package the extension locally with Node.js and pnpm:

pnpm install
pnpm run package

The package script runs vsce package --no-dependencies and writes a versioned .vsix in the project root.

Automated releases

Pushes to main trigger a release workflow that bumps the patch version, packages the extension, and creates a GitHub Release. Publishing to the Visual Studio Marketplace is a separate step — see the README for details.
