Midnight Ocean

Four minimalist dark themes for VS Code — calm, focused, refined.

Deep, low-glare backgrounds paired with subtle ocean accents so your code stands out while your eyes rest.

Install

Download the VSIX and install in VS Code.

code --install-extension ./midnight-ocean.vsix

Build from source

Requires Node.js and pnpm.

pnpm install
pnpm run package
